# The fonts in this directory

Two typefaces are vendored here as `woff2` so the design previews render the
same on any machine. Both are under the SIL Open Font License 1.1, which
allows redistribution with the licence; neither is part of the program.

| Instrument Serif | `InstrumentSerif-*.woff2` | Copyright © 2022 The Instrument Serif Project Authors | [SIL OFL 1.1](https://github.com/Instrument/instrument-serif/blob/main/OFL.txt) |

The OFL asks that the fonts not be sold on their own, that any modified
version carry a different name, and that this notice travel with the files.
The rest of this repository is under the AGPL (see `LICENSE`); the licences
do not mix, because the fonts are data the previews load, not code.
