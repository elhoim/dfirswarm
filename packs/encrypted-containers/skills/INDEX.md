# Skills in this pack

Fetch a body with `skill("<id>")`. A body may name others; fetch those the same way.

- `archives/protected` Archives and documents with a password: A file inside the evidence will not open without one.
- `identify/headers` Which kind of encryption this is, before spending anything on it: A volume, a file or an archive will not open.
- `keys/where-they-hide` Locating and safeguarding authorised key material: A case question requires access to encrypted evidence.
- `volumes/bitlocker` BitLocker protectors and authorised examination: A Windows volume may use BitLocker.
- `volumes/luks-filevault` LUKS and FileVault: A Linux or macOS volume is encrypted.
