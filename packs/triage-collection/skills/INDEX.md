# Skills in this pack

Fetch a body with `skill("<id>")`. A body may name others; fetch those the same way.

- `gaps/what-is-missing` What a logical acquisition cannot contain: Writing up anything based on a collection.
- `identify/collector` Which tool made this, and what that tells you: The evidence is a directory tree or an archive rather than an image.
- `normalise/layout` The paths in the tree are not the paths on the machine: Before you cite anything by path.
- `plan/what-to-collect` What to ask for, when a collection is still being planned: The operator can still influence what is collected.
- `verify/manifests` The collector's own record, and how to check it: Taking custody of a collection.
