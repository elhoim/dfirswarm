# The tour

`dfirswarm-belkactf6-tour.mp4` — 2 min 49 s, 1920×1080. A guided walk through
the console on run `s83fd`, captioned for a reader who does forensic work:
what is held, what is recorded, and where the record is honest about its own
limits. `poster-escape.jpg` is the frame to put in front of it.

It is not a screen recording of a desktop. It is the console itself, driven
by a script, with the captions drawn into the page — so every frame is the
real product at one size, and the cut can be re-made after the console
changes.
