### Added: encrypted-containers, triage-collection, mobile-forensics, network-forensics and cloud-forensics each have a router, so a run that carries them stays inside the skills index budget

Each of the five packs names one router (`encrypted/router`, `triage/router`, `mobile/router`, `network/router`, `cloud/router`), at most 400 tokens (the largest is about 270), opening with "Use when ... Not for ...". When a run's index is over its 2,500-token budget the prompt shows each router-bearing pack by its router's one line, and the router names every other skill of its pack exactly once, grouped by topic, with a few words on when to read it. A router holds no rule and names no tool or program; it is read alone. Every existing skill id is unchanged, so what other packs need or mention still resolves. The pack indexes grow by one entry each (encrypted-containers 363 to 395 tokens of entries as the harness counts them, triage-collection 408 to 438, mobile-forensics 285 to 310, network-forensics 409 to 435, cloud-forensics 335 to 360; the limit is 1,000). Measured with `extensions/skills.ts`: the `full` profile shows 6,014 tokens of entries instead of 7,676, and 5,150 instead of 6,812 once the base pack has its router; the mobile-forensics and windows-forensics combination (with macos-forensics, which mobile-forensics needs) goes from 2,713 to 2,453 tokens, under the 2,500 run budget, only with the base pack's router and the mobile one together. `tests/pack-router-checks.ts` holds the checks, and the pull request lists the table. Packs `encrypted-containers`, `triage-collection`, `mobile-forensics`, `network-forensics` and `cloud-forensics`.

### Changed: the link check no longer reads a skill cited by its id as naming a program

A router cites every leaf of its pack by id, and `aws/cloudtrail` spells the program `aws`. `tests/pack-links.test.sh` already left a skill's own `id:` and `needs:` lines out of what counts as naming a program; it now leaves out a body's citation of a skill of the same pack by its id as well, and a fixture case holds it. A program named in prose or code is found as before.
