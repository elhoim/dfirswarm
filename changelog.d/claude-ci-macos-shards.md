### Changed: the macOS CI job runs in three parts side by side, with every test still run

The one macOS job took 44 minutes of its 55-minute limit (typecheck and node tests 12, shell suites 31, three pushes to main). It is now a matrix of three jobs: typecheck plus every node suite, and the shell suites in two shards (`scripts/test-bash.sh --shard 1/2` and `2/2`), dealt out by how long each suite takes (`tests/shell-suites.weights`; a suite it does not know counts as 20 seconds). `--shard` with no value or an empty one is refused with exit 2. The limit stays at 55 minutes. `tests/ci-shards.test.ts` reads the workflow and the script and fails if a shell suite is in no shard or in two, or if the node suites are not all run by one part. The macOS check names change: `macOS · typecheck · node tests · shell suites` becomes `macOS · typecheck · node tests`, `macOS · shell suites 1/2` and `macOS · shell suites 2/2`. No harness, pack or skill file changes.
