### Security: the triage tools follow the secret-safe output pattern

Both tools print paths and the text of collectors' logs, and a path or a UAC command line can carry a credential. They now withhold, in every channel (a path, a log line, an error, the files the answer names), a string shaped like a BitLocker recovery password, an access key id, a GitHub, Slack, OpenAI-style or JSON web token, a private-key header or the user-info of a URL, by one block of code carried in both (`tests/pack-triage-shared.test.ts` holds the two copies equal and holds the shapes to a table of strings written from the formats, GUIDs, hashes and cache names among the names it leaves alone). The shapes are few and exact, so a secret of no recognisable shape can still appear in a log: the manifests say to run the tools as jobs with `secret_output: true`. `write_values: true` (refused outside a job, created exclusively, mode 0600, before anything is read; a second run in the same job is refused by name and leaves the first file) writes the real strings to `$OUT/collection-id-values.jsonl` or `$OUT/collection-index-values.jsonl`. `collection_index` marks a file whose name says it is a credential store (`may_hold_secrets`, a name hint and nothing more) and does not hash it unless `hash_credential_stores: true`, which is refused outside a job.

### Changed: the triage tool manifests say what each tool reads and does not measure

Each manifest has a `use` (the collectors' marker file names), says what is and is not measured, names exactly the parameters its script reads (`tests/pack-triage-shared.test.ts` holds both to the script) and carries its raised version and the sha256 of its script. In a job the run directory is read-only and only `$OUT` is written: both tools write there, never elsewhere, and a place that cannot be written is a JSON error. Both take `time_limit_seconds` and stop with an answer before the manifest's timeout (raised to 3600). New suites (`tests/pack-triage-*.test.ts`, 54 cases; 2 skip where the file system refuses a name that is not UTF-8) build their fixtures from the formats' own definitions (the EWF, VHDX and LiME signatures, a GPT header at offset 512, the column names of a real KAPE copy log, JSON Lines) or by hand, never from a tool's output. All 46 cases that run here and exercise the two tools fail on the tools as they were (several because the old answer has no field the new contract names; the defects above are each one of them). The README follows; the skills, the goal template and `requires` are the pack's next pull request. Collector manifests are read only as far as the KAPE copy, skip and console logs, UAC's log lines and Velociraptor's JSON Lines index; UAC's and Velociraptor's schemas are not verified here, and `collection_manifest_parse`, `collection_manifest_verify`, `collection_path_map`, `collection_coverage` and the `collection_intake` recipe are Phase 2.
